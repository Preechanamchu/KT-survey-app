Auto-Deploy & Release System

KT Survey Pro — ระบบอัปโหลด APK ขึ้น GitHub

ส่งไฟล์ติดตั้ง APK ขึ้น GitHub Releases ใน 1 คลิก เพื่อให้ผู้ใช้งานในมือถือกด "อัพเดทแอป" และติดตั้งเวอร์ชันใหม่ได้ทันที

วงจรการทำงานแบบสมบูรณ์ (Workflow)

1. ติดตั้งแอปครั้งแรก
ผู้ใช้ติดตั้งไฟล์ APK ลงในมือถือ Android 1 ครั้ง
2. อัปโหลด APK ใหม่
คุณลากไฟล์ APK ใส่หน้านี้แล้วกดส่งขึ้น GitHub
3. กดอัพเดทในมือถือ
ผู้ใช้เข้าแถบ "ผู้ใช้" ➔ กดปุ่ม "อัพเดทแอป"
4. ติดตั้งใหม่อัตโนมัติ
ระบบดาวน์โหลดและเปิดตัวติดตั้งอัปเดตทับทันที
