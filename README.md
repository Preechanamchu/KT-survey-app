# KT Survey Pro — ระบบอัปเดตและปล่อยไฟล์ติดตั้ง APK ผ่าน GitHub

คลังนี้จัดเตรียมชุดโปรแกรมและเครื่องมือสำหรับอัปโหลดไฟล์ **APK (Android)** ขึ้น **GitHub Releases** เพื่อให้ผู้ใช้งานแอปพลิเคชัน KT Survey Pro ในมือถือสามารถกดปุ่ม **"อัพเดทแอป"** และรับไฟล์ติดตั้งเวอร์ชันล่าสุดไปอัปเดตได้โดยตรงทันทีอย่างราบรื่น

---

## 🚀 โครงสร้างไฟล์ในชุดโปรแกรม

| ชื่อไฟล์ | คำอธิบาย |
|---|---|
| `start_uploader.bat` / `คลิกเปิดระบบอัพโหลด.bat` | ดับเบิ้ลคลิกเพื่อเปิดหน้าจอ Dashboard อัปโหลดไฟล์ APK ผ่านเว็บเบราว์เซอร์ |
| `server.py` | เว็บเซิร์ฟเวอร์ขนาดเล็กสำหรับประมวลผลการส่งข้อมูลขึ้น GitHub REST API |
| `index.html` | หน้าโปรแกรม Web Dashboard ที่มีดีไซน์ทันสมัย ลากวางไฟล์ APK ได้ |
| `quick_upload.bat` / `cli_upload.py` | เครื่องมืออัปโหลดอย่างรวดเร็ว (สามารถลากไฟล์ `.apk` มาปล่อยใส่ไฟล์ `.bat` ได้) |
| `config.json` | ไฟล์บันทึกการตั้งค่า GitHub Owner, Repo และ Token ในเครื่อง |
| `คู่มือการใช้งาน_ภาษาไทย.md` | คู่มือแนะนำการใช้งานอย่างละเอียดทุกขั้นตอน |

---

## 📱 วงจรการทำงาน (Workflow)

```
[ คุณบิลด์ APK ] ➔ [ ลากไฟล์ลงในหน้าอัปโหลด ] ➔ [ ระบบส่งขึ้น GitHub Releases ]
                                                          │
                                                          ▼
[ ติดตั้งอัปเดตทับทันที ] ◄─ [ กดปุ่ม "อัพเดทแอป" ในมือถือ ] ◄─ [ ตรวจพบเวอร์ชันใหม่ ]
```

---

## 📖 วิธีใช้งานด่วน

1. ดับเบิ้ลคลิกที่ไฟล์ **`คลิกเปิดระบบอัพโหลด.bat`** (หรือ `start_uploader.bat`)
2. ใส่ข้อมูล **GitHub Owner**, **Repo Name** และ **Personal Access Token**
3. ลากไฟล์ **`.apk`** มาวางในช่อง หรือคลิกเลือกไฟล์ล่าสุดที่ระบบตรวจพบ
4. กดปุ่ม **"เริ่มอัปโหลดไฟล์ APK ขึ้น GitHub"**
5. ให้ผู้ใช้งานเปิดแอปในมือถือ ➔ ไปที่แท็บ **"ผู้ใช้"** ➔ กดปุ่ม **"อัพเดทแอป"** ได้ทันที!
